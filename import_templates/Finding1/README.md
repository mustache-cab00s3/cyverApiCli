# Finding1 Custom Import Instructions

This folder is a ready-to-run example for:

- `cyverApiCli pentester findings custom-import`

`custom-import` uses supported v2.2 API calls only (no legacy app-service endpoints).

## Folder contents

- `findings_import.json` - finding manifest with nested `evidences` array
- `SqlInjection.png` - local evidence file referenced by evidence data
- Optional snapshots generated by import:
  - `<finding-guid>.json`

## Manifest expectations

`findings_import.json` should include one finding object and an `evidences` array.

**Finding fields:**
- `code`, `name`/`title`, `description`
- `type`, `status`, `severity`
- `recommendation`, `backgroundInformation`
- `cweList`, `cveList`, `mitreAttackTacticsList`, etc.
- `assetIdList`, `labelIdList`
- `cvss`
- `evidences` or `findingEvidenceList`

**Each evidence item supports:**
- `title` (required), `location`, `version`, `reproduce`, `results`, `issueDetails`
- `isVisibleInReport` (default: true)
- `ip`, `hostname`, `port`, `protocol`
- `assetId`, `evidenceComplianceStatus`
- `files` (array of local file names, e.g. `["SqlInjection.png"]`)

## Workflow (supported v2.2 only)

1. Upload referenced evidence files via `POST /api/v2.2/pentester/projects/{id}/upload-file` and capture `fileToken`.
2. Create finding via `POST /api/v2.2/pentester/findings`.
3. Create each evidence via `POST /api/v2.2/pentester/findings/{findingId}/evidences` with `evidenceFiles` token array.
4. Update finding via `PUT /api/v2.2/pentester/findings/{id}` with `findingEvidenceList`.
5. Write snapshot `<finding-guid>.json` for traceability.

## Run command

From the `cyverApiCli` directory:

```bash
./cyverApiCli -p sandbox pentester findings custom-import --project-id <PROJECT_UUID> ./import_templates/Finding1
```

Use `-vvv` for full debug HTTP traces:

```bash
./cyverApiCli -vvv -p sandbox pentester findings custom-import --project-id <PROJECT_UUID> ./import_templates/Finding1
```

Use `--batch` to recursively import all directories containing `findings_import.json`:

```bash
./cyverApiCli -p sandbox pentester findings custom-import --project-id <PROJECT_UUID> ./import_templates --batch
```
